# Προσομοίωση ομάδας — UI 1.1-sim.1

Η καρτέλα **Προσομοίωση ομάδας** στα πειράματα εμφανίζει το ρομπότ, το καρότσι της εργασίας, τα μέλη H1–H3 και την επόμενη καταγεγραμμένη ενέργεια. Η διάταξη είναι σχηματική: δεν προσομοιώνει φυσική κίνηση, θέσεις ή χειρουργική πράξη.

Από την αρχική σελίδα, το **Άνοιγμα offline προσομοίωσης** δημιουργεί και εκτελεί την υπάρχουσα offline σουίτα χωρίς API calls. Για προηγούμενα live δεδομένα άνοιξε το αντίστοιχο πείραμα και την καρτέλα προσομοίωσης. Το offline LLM είναι fixture, όχι νέο αποτέλεσμα μοντέλου.

Χρησιμοποίησε **Προηγούμενο**, **Επόμενο** ή τον δείκτη γύρου για να δεις τα καταγεγραμμένα στιγμιότυπα. Το σκηνικό δείχνει τη διαθέσιμη πληροφορία πριν από την επιλεγμένη ενέργεια. Δεν αναπαράγει αυτόματα πειράματα ούτε στέλνει ερωτήματα AI. Η ιστορία εμφανίζει μόνο προηγούμενες ενέργειες. Οι μετρήσεις πάνω από τον δείκτη αφορούν το σύνολο του επεισοδίου.

Η κατάσταση του καροτσιού υπολογίζεται από τις αποδεκτές αναφορές του μοντέλου και τα δημόσια στοιχεία message ID, χρόνου, TTL, aliases και conflict. Αν δεν υπάρχει έγκυρη αναφορά ή υπάρχει αντίφαση, η κατάσταση παραμένει άγνωστη. Οι πιθανότητες γνώσης είναι δημόσιες εκτιμήσεις, όχι η πραγματική γνώση των μελών. Ο πίνακας δεν διαβάζει private truth ή simulator annotations. Οι υφιστάμενοι διαγνωστικοί έλεγχοι αξιολόγησης παραμένουν ξεχωριστά παρακάτω.

Τα prompts, οι controllers, τα δεδομένα και οι κανόνες του simulator δεν αλλάζουν. Η αλλαγή αφορά απεικόνιση και πλοήγηση στις αποθηκευμένες εκτελέσεις.

Έλεγχος: `node test_frontend_smoke.cjs` (Node VM / mock DOM, όχι πραγματικός browser). Περιλαμβάνει έλεγχο διαδρομών, επιλογής επεισοδίου, πλοήγησης γύρων, TTL/aliases, αρχικής άγνωστης κατάστασης, μη εμφάνισης μελλοντικών ενεργειών και escaping κειμένου. Για οπτικό έλεγχο άνοιξε την εφαρμογή τοπικά και δοκίμασε και στενό παράθυρο.
